## Background

`superpipelines-opencode` was a sibling GitHub repo that distributed this plugin to OpenCode users. Yesterday it was declared obsolete. Two consequences:

1. Every reference to the sibling repo (URL constant, install-script handler, sync invariants, design-spec mentions) must disappear from the active surface of this repo.
2. OpenCode platform support (Tier 1b in `sk-platform-dispatch/profiles/tier_1b.json`) remains functional — fixtures, resolver branches, profile data, and all platform-fact mentions stay. Only the *sibling repo as a thing that exists* is being retired.

Independently, the `/audit-pipeline` command name was identified as misleading because users assumed it audited the superpipelines bundle itself, while in normal use it audits user-created pipelines under a scope root. Renamed to `/audit-steps` for clarity. The underlying agent retains its `path/glob` capability — invoking the agent directly on a framework path is still the mechanism by which PR-01..PR-07 (added 2026-05-25) fire against the plugin tree.

This plan is itself a temporary artifact. Its final task is its own deletion (Task 7). After execution `docs/superpowers/plans/` is empty and the directory is removed.
